 C String Programs
This repository contains a collection of basic to intermediate C programs focused on string manipulation.
These programs were written as part of practice during my first year of B.Tech (CSE) to strengthen logic building and understanding of strings in C.

🧠 Topics Covered
The programs in this repository cover commonly asked academic and interview-oriented string problems, including:


Word and character analysis


String traversal using loops


Logical problem solving without advanced libraries


Practice with arrays, conditions, and nested loops
